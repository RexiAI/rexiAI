# AC-001: i18n dictionary + language switcher

## AC-001-01 — Default language is Spanish
Given a visitor with no stored language preference (empty `localStorage`)
When the landing page is rendered
Then all user-facing copy is rendered in Spanish from the Spanish dictionary

## AC-001-02 — Switching to English
Given the page is rendering in Spanish
When the English option of the language switcher is activated
Then every visible user-facing string switches to its English dictionary value

## AC-001-03 — Switching back to Spanish
Given the page is rendering in English
When the Spanish option of the language switcher is activated
Then every visible user-facing string switches back to its Spanish dictionary value

## AC-001-04 — Language choice persists across reload
Given the visitor has switched the page to English
When the page is reloaded
Then the page renders in English without the visitor touching the switcher again

## AC-001-05 — No hardcoded user-facing strings in components
Given the SPA source tree
When component files are inspected for literal user-facing text
Then every rendered string resolves to an entry present in both locale dictionaries
